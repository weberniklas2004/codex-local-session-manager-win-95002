## About Codex Local Session Manager

Codex Local Session Manager is a lightweight browser tool for viewing and managing Codex session history locally. It is built as a single HTML file, so you can open it directly in the browser and work with session data without setting up a server or connecting to a backend.

The tool is designed for people who need a faster way to review long conversation histories, find specific sessions, and remove outdated entries. It combines browsing, previewing, and cleanup actions in one place, which makes it practical for day-to-day session organization.

## Features

- Browse Codex session history locally in the browser
- Search sessions to find specific conversations faster
- Filter session lists to narrow down results
- Paginate through large history sets more comfortably
- Preview full conversation content for each session
- Delete the current session, selected sessions, or everything at once
- Works as a single-file HTML tool with no backend dependency
- Focuses on local session cleanup and review workflows

## FAQ

### Does it need an internet connection?
No backend is required. The tool is designed to run in the browser from a local file.

### How do I update it?
Download the latest build and replace your current file with the new version.

### Why am I not seeing the sessions I expect?
Check your search terms, filters, and pagination state. If the history is large, the session may be on another page.

### Can I restore deleted sessions?
Deletion actions remove entries from the local session view, so confirm carefully before cleaning up data.

### Where can I change settings?
If your build includes settings, they are usually available in the interface or stored locally in the browser context.
